# Установка Firefox Control на Windows

Инструкция для версии 0.3.1. Обновлено 10 ноября 2026 года.

Firefox Control состоит из локального плагина для Codex и подписанного расширения Firefox. На новом компьютере нужны обе части. Настройка выполняется один раз; расширение сохраняется после перезапуска Firefox.

## 1. Подготовь компьютер

- Windows 10 или 11.
- Firefox 142 или новее.
- Настольное приложение Codex с поддержкой плагинов. Установи его и войди в свой аккаунт.
- [Node.js LTS](https://nodejs.org/en/download), версия 22 или новее. Выбери установщик для Windows. После установки заново открой PowerShell, чтобы он увидел Node.js.

Локальный плагин работает с приложением на этом компьютере. Одна вкладка ChatGPT в браузере не запускает его.

## 2. Скачай два файла

Открой [выпуск Firefox Control 0.3.1](https://github.com/andsobolev/firefox-control/releases/tag/v0.3.1-preview.1). В разделе **Assets** находятся:

| Файл | Для чего нужен |
| --- | --- |
| [firefox-control-0.3.1-windows-candidate.zip](https://github.com/andsobolev/firefox-control/releases/download/v0.3.1-preview.1/firefox-control-0.3.1-windows-candidate.zip) | Локальный плагин и установщик Windows |
| [firefox-control-0.3.1-signed.xpi](https://github.com/andsobolev/firefox-control/releases/download/v0.3.1-preview.1/firefox-control-0.3.1-signed.xpi) | Подписанное Mozilla расширение Firefox |

Для установки используй именно подписанный `.xpi`. Архивы `unsigned.zip` и `reviewer-source.zip` предназначены для подготовки и проверки выпуска.

## 3. Установи локальный плагин

1. Нажми правой кнопкой по скачанному ZIP → **Извлечь всё**. Распакуй его в папку внутри своих «Загрузок».
2. Открой распакованную папку, в которой виден файл `Install-Windows.ps1`.
3. В адресной строке Проводника введи `powershell` и нажми Enter. Откроется окно PowerShell в этой папке. Права администратора для установки плагина не нужны.
4. Скопируй и выполни команду проверки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Windows.ps1 -CheckOnly
```

При успехе появится `Prerequisites and package verified. No changes made.`
Если проверка выдала ошибку, сначала исправь её по подсказке в окне или разделу ниже.

5. После успешной проверки выполни установку:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Windows.ps1
```

Установщик копирует плагин в постоянную папку профиля пользователя, регистрирует его в Codex и создаёт файл подключения для этого компьютера. В конце должно появиться `Local plugin installed.`

Параметр `-ExecutionPolicy Bypass` действует в запущенном процессе PowerShell и не меняет системную политику постоянно. [Описание параметра Microsoft](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_powershell_exe#-executionpolicy-executionpolicy).

## 4. Запусти подключение в Codex

Полностью закрой Codex и открой снова, чтобы приложение загрузило установленный плагин. Проверь, что Firefox Control доступен и включён.

В чате напиши:

> Используй Firefox Control и проверь подключение Firefox.

Вызов инструмента запускает локальный мост. До настройки расширения отсутствие подключённого профиля ожидаемо — переходи к следующему шагу.

## 5. Установи расширение Firefox

1. В адресной строке Firefox введи `about:addons` и нажми Enter.
2. Нажми шестерёнку → **Установить дополнение из файла**.
3. Выбери `firefox-control-0.3.1-signed.xpi` и подтверди разрешения Firefox.

В списке дополнений оно называется **Browser Control Bridge for Firefox**. Установка постоянная: загружать расширение заново после закрытия Firefox не нужно.

## 6. Соедини расширение с локальным плагином

Откроется страница «Подключение Firefox к ИИ-ассистенту». Если она не открылась, зайди в настройки установленного дополнения через `about:addons`.

1. В поле **Файл подключения** нажми кнопку выбора файла.
2. В поле имени файла диалога Windows вставь следующий путь и нажми **Открыть**:

```text
%LOCALAPPDATA%\FirefoxControl\firefox-control-connection.json
```

3. Прочитай описание доступа и поставь галочку согласия.
4. Нажми **Подключить**.

Ожидаемый статус: **«Подключено к локальному плагину.»**

Файл подключения появляется только после успешной установки на шаге 3. На каждом компьютере создаётся свой файл. Он содержит ключ доступа: не переноси его со старого ПК и не отправляй в GitHub, Mozilla или чат.

## 7. Проверь работу

Открой обычную веб-страницу в Firefox и напиши в Codex:

> Покажи мои открытые вкладки Firefox.

После получения списка можно попросить:

> Найди вкладки с одинаковыми адресами и предложи, какие дубли закрыть.

Для остановки доступа нажми **Приостановить доступ** в панели расширения. Для продолжения — **Возобновить доступ**. Приватные окна и защищённые служебные страницы Firefox недоступны плагину.

## Если что-то не получилось

| Сообщение или проблема | Что сделать |
| --- | --- |
| Не найден `Install-Windows.ps1` | Полностью распакуй ZIP и открой PowerShell именно в папке с этим файлом. |
| Не найден Node.js или требуется версия 22+ | Установи подходящую Node.js LTS и заново открой PowerShell. |
| Codex не найден или не поддерживает установку плагинов | Установи или обнови настольное приложение Codex, запусти его и повтори проверку `-CheckOnly`. |
| Файл `firefox-control-connection.json` отсутствует | Шаг 3 не завершился успешно. Найди ошибку установщика; не создавай JSON вручную. |
| `Local connection unavailable. Open Codex to start the bridge.` | В Codex попроси проверить Firefox через Firefox Control, затем нажми **Переподключить** в расширении. |
| В Codex нет Firefox Control | Полностью перезапусти приложение после установки и проверь список доступных плагинов. |
| Доступ приостановлен | Нажми **Возобновить доступ** в расширении. |

Если ошибка остаётся, сохрани её текст и укажи, на каком шаге она возникла. [Поддержка через GitHub Issues](https://github.com/andsobolev/firefox-control/issues). Не прикладывай файл подключения или личные данные со страниц.

Версия 0.3.1 пока помечена как предварительная. Подпись XPI проверена обычным Firefox в отдельном профиле; полный сценарий установки под новым пользователем Windows ещё предстоит проверить. Подписанный файл можно устанавливать из этого выпуска независимо от наличия карточки в каталоге Mozilla.
